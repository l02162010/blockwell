# 實機輸入法測試清單

自動化測試（`apps/playground/e2e`）會在 Chromium、Firefox、WebKit 與 Android／iPhone 模擬器上跑每個 demo，並在 Chromium 上用 DevTools 協定模擬輸入法組字。真正的輸入法在實機上的行為無法自動化，發版前請在下列裝置各跑一次本清單。

測試頁：<https://l02162010.github.io/blockwell/playground/>（「01 全頁文件編輯」與「02 嵌入場景」）。

## 裝置與輸入法

| 平台 | 瀏覽器 | 輸入法 |
| --- | --- | --- |
| macOS | Safari、Chrome | 注音、倉頡、拼音 |
| Windows 11 | Edge、Chrome | 微軟注音、新注音 |
| iOS 17+ | Safari | 注音、手寫、倉頡 |
| Android 14+ | Chrome | Gboard 注音、Gboard 手寫 |

## 每個組合都要跑的情境

每一項：照步驟操作，結果符合「預期」才打勾。不符合時記下裝置、瀏覽器、輸入法版本與螢幕錄影。

### 基本組字
- [ ] 在段落中間輸入「中文輸入」，選字後文字出現在游標處，游標在最後一個字後面。
- [ ] 連續輸入多個詞不停頓（例如「今天天氣很好」逐詞選字），每個詞都出現，沒有重複或遺漏。
- [ ] 組字中（候選字還沒選）點擊別處：候選字被確認或放棄，都不會出現亂碼或重複字。
- [ ] 組字中按 Esc 或刪除全部注音：文件內容與組字前完全相同。

### Enter 與換行
- [ ] 選字後立刻按 Enter（不停頓）：在選好的字後面分段，新段落是空的。
- [ ] 組字中按 Enter（用來選字的輸入法，例如部分注音設定）：只確認候選字，不會分段。
- [ ] 在清單項目中選字後按 Enter：產生新的清單項目。
- [ ] 在程式碼區塊中選字後按 Enter：換行，不離開程式碼區塊。

### 格式
- [ ] 在粗體字中間組字：新字是粗體。
- [ ] 在連結文字中間組字：新字在連結內。
- [ ] 選取一段文字後直接組字：選取的文字被取代。
- [ ] 跨兩個段落選取後組字：兩段合併，選取範圍被取代。
- [ ] 組字完成後按 ⌘Z／Ctrl+Z：一次復原整個詞，不是一個注音符號。

### 特殊位置
- [ ] 空白文件（只有提示文字）中組字：提示消失，文字正確。
- [ ] 提及（@名字）後面組字：文字在提及之後。
- [ ] 表格儲存格中組字：文字在該格，Tab 後到下一格。
- [ ] 待辦清單、引言中組字：文字正確，區塊類型不變。
- [ ] 輸入「/」後用輸入法打中文搜尋（例如「/標題」）：選單依中文篩選。

### 手機
- [ ] 點進文字後鍵盤上方出現工具列；收起鍵盤後工具列消失。
- [ ] 選取文字後工具列變成格式列（粗體、斜體…），按粗體生效。
- [ ] 「+」開啟底部面板；面板開啟時鍵盤收起；選一個區塊後面板關閉。
- [ ] 手寫輸入一段文字：文字正確，沒有重複。
- [ ] 語音輸入一句話：文字正確，沒有重複。
- [ ] 系統的拼字建議／自動更正被接受時：文字正確更新。
- [ ] 旋轉螢幕後繼續輸入：游標位置正確。
